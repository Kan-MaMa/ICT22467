📋 ภาพรวมระบบ (System Overview)
Elderly Care System — Smart Health & Emergency Monitoring
ระบบดูแลผู้สูงอายุอัจฉริยะแบบครบวงจร ที่ผสานการทำงานระหว่างเทคโนโลยีเว็บและ IoT (Internet of Things) ออกแบบมาเพื่อผู้ดูแล (Caregiver) ให้สามารถติดตามสัญญาณชีพ (Vital Signs) ได้แบบ Real-time และมีระบบแจ้งเตือนเหตุฉุกเฉินหรือการล้มทันที โดดเด่นด้วยดีไซน์ Dashboard ที่ทันสมัย กราฟิกดูง่าย และใช้งานได้อย่างมีประสิทธิภาพ

เทคโนโลยีและเครื่องมือที่ใช้ (Tech Stack & Tools)
โปรเจกต์นี้ใช้เทคโนโลยีที่ทันสมัยและได้มาตรฐานอุตสาหกรรม:
1. Front-end Framework: React.js (ผ่าน Vite เพื่อความรวดเร็ว)
2. Styling & UI: Tailwind CSS (จัดการเลย์เอาต์และความสวยงาม)
3. Database & Backend: Firebase Cloud Firestore (ฐานข้อมูลแบบ Real-time)
4. IoT & Communication: Node-RED (จำลองและจัดการ Flow ข้อมูล) + MQTT.js (เชื่อมต่อผ่าน EMQX Broker)
5. Data Visualization: Recharts (สำหรับสร้างกราฟสัญญาณชีพที่สวยงาม)
6. Icons & Alerts: Lucide-React (ไอคอนมินิมอล) + React-Hot-Toast (ป๊อปอัปแจ้งเตือน)

วิธีติดตั้ง Library
1. react-router-dom ใช้สำหรับจัดการระบบนำทาง (Routing) ภายในหน้าเว็บแบบ Single Page Application (SPA) ทำให้เปลี่ยนหน้าได้ลื่นไหลโดยไม่ต้องโหลดหน้าเว็บใหม่
วิธีติดตั้ง : npm install react-router-dom

2. firebase เป็นตัวกลางเชื่อมต่อกับบริการ Backend as a Service (BaaS) ของ Google ใช้เชื่อมต่อกับ Cloud Firestore เพื่อทำหน้าที่เป็นฐานข้อมูล (Database) หลักของระบบ
วิธีติดตั้ง : npm install firebase

3. mqtt ใช้เป็นโปรโตคอลสื่อสารหลักสำหรับงาน IoT (Internet of Things) ทำหน้าที่เชื่อมต่อหน้าเว็บ (Client) เข้ากับเซิร์ฟเวอร์ EMQX Broker ผ่าน WebSockets (wss://) ใช้ฟังก์ชัน client.subscribe() เพื่อดักฟังข้อมูลสัญญาณชีพ (หัวใจ, ความดัน, ออกซิเจน) ที่ถูกส่งมาจาก simulator
วิธีติดตั้ง : npm install mqtt

4. recharts ไลบรารีสำหรับสร้างกราฟ (Data Visualization) ที่ถูกออกแบบมาเพื่อ React โดยเฉพาะ ใช้สร้างกราฟพื้นที่ (AreaChart) เพื่อแสดงแนวโน้มของสัญญาณชีพย้อนหลัง 10 ครั้ง
วิธีติดตั้ง : npm install recharts

5. lucide-react ชุดไอคอนแบบเวกเตอร์ (SVG Icons) ที่มีความมินิมอลและสวยงาม ใช้ตกแต่ง User Interface (UI) ทั่วทั้งโปรเจกต์
วิธีติดตั้ง : npm install lucide-react

6. react-hot-toast ระบบจัดการการแจ้งเตือนแบบป๊อปอัป (Toast Notifications) ใช้สำหรับแสดงข้อความตอบกลับผู้ใช้ (Feedback) ในมุมจอ เช่น การแจ้งเตือนสีเขียวเมื่อ "บันทึกข้อมูลสำเร็จ" หรือการเด้งป๊อปอัปสีแดงเมื่อ "พบความผิดปกติของสัญญาณชีพ"
วิธีติดตั้ง : npm install react-hot-toast

7. Tailwind CSS เป็น Utility-first CSS Framework ใช้สำหรับเขียนสไตล์การตกแต่งหน้าเว็บโดยตรงผ่าน className
วิธีติดตั้ง : npm install -D tailwindcss postcss autoprefixer

เค้าโครงสีหลักของแบรนด์ (Brand Theme)
- ระบบออกแบบมาในธีม Modern Healthcare เน้นความสะอาดตา สบายใจ และมองเห็นความผิดปกติได้ชัดเจน
- Slate/White (ขาว-เทาอ่อน): สีพื้นหลังหลัก ให้ความรู้สึกมินิมอล สะอาด และเป็นระเบียบ (Clean UI)
- Emerald Green & Cyan (เขียวมรกต-ฟ้า): สีของความปลอดภัย สุขภาพที่ดี และสถานะการเชื่อมต่อที่สมบูรณ์
- Rose Red & Amber (แดงกุหลาบ-เหลืองอำพัน): สีสำหรับดึงดูดสายตา ใช้ในส่วนของค่าอัตราการเต้นหัวใจ, ความดันโลหิต, และการแจ้งเตือนเหตุฉุกเฉิน (Emergency Alerts)

📖 คู่มือการใช้งานระบบ (User Manual)
ฟีเจอร์หลักของระบบแบ่งออกเป็นหน้าต่างๆ ดังนี้:
- แดชบอร์ดหลัก (/dashboard): หน้าสรุปภาพรวมทั้งหมด แสดงจำนวนผู้สูงอายุในความดูแล, สถิติเหตุฉุกเฉิน และสถานะอุปกรณ์แบบย่อ
- ระบบติดตามสัญญาณชีพ (/vitals): แดชบอร์ดดูกราฟสัญญาณชีพแบบ Real-time (Heart Rate, SpO2, Blood Pressure) ที่ดึงข้อมูลผ่าน MQTT พร้อมระบบแจ้งเตือนป๊อปอัปทันทีหากค่าผิดปกติ
- จัดการข้อมูลผู้สูงอายุ (/elderly & /elderly-table): ระบบเพิ่ม/ลบ/แก้ไข ประวัติส่วนตัว ข้อมูลทางการแพทย์ และประวัติการรับยาของผู้สูงอายุแต่ละท่าน
- บันทึกเหตุฉุกเฉิน (/emergency-table): ตารางบันทึกประวัติการกดปุ่ม SOS หรือเหตุการณ์การล้ม พร้อมระบุเวลา สถานะการช่วยเหลือ และพิกัด
- ระบบแจ้งเตือนครอบคลุม (Global Alert): ไม่ว่าจะอยู่หน้าไหน หากมีเหตุฉุกเฉินเข้ามา ระบบจะเด้งแถบสีแดงแจ้งเตือนให้ผู้ดูแลทราบทันที

วิธีนำโปรเจกต์นี้ไปรันในเครื่อง
1. Clone Project: นำไฟล์โปรเจกต์ลงเครื่อง
2. เปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วพิมพ์คำสั่ง: npm install (เช็คด้วยว่าในเครื่องมี node.js หรือยังโดยการพิมพ์คำสั่ง node -v ถ้าไม่ขึ้นเวอร์ชันให้ทำการติดตั้ง)
3. ตั้งค่า Firebase: ตรวจสอบไฟล์ src/services/firebase.js ว่ามีการใส่ Config API Key ตรงกับฐานข้อมูลหรือไม่
4. รันระบบ: พิมพ์คำสั่งด้านล่างเพื่อเปิดหน้าเว็บ: npm run dev
